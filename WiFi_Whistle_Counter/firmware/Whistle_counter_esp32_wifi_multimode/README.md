# Arduino IDE setup for this sketch

This folder targets **ESP32 Dev Module (original ESP32 / ESP-WROOM-32)**.
For the installed **Generic ESP8266 Module**, open
[`Whistle_counter_esp8266_wifi_multimode`](../Whistle_counter_esp8266_wifi_multimode/README.md)
instead. The ESP32 version cannot run on ESP8266 hardware.

1. In **File > Preferences > Additional Boards Manager URLs**, add:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. Open **Tools > Board > Boards Manager** and install **esp32 by Espressif
   Systems**, version **2.0.17**.
3. Select **Tools > Board > esp32 > ESP32 Dev Module**. Selecting NodeMCU or
   another ESP8266 board does not enable the ESP32 libraries.
4. Install **LiquidCrystal_I2C 1.1.4** (Frank de Brabander / Marco Schwartz).
   ZIP installation instructions are in the repository-root `requirements.txt`.
5. Open `Whistle_counter_esp32_wifi_multimode.ino` in this folder and click Verify.

This workspace was also successfully compiled with Arduino CLI, ESP32 core
2.0.17, and the already installed **LiquidCrystal_I2C 2.0.0** by Martin
Kubovcik / Frank de Brabander. That existing installation can be kept;
PlatformIO continues to use the pinned 1.1.4 implementation.

| Header | Provided by |
| --- | --- |
| `HTTPClient.h` | ESP32 board package 2.0.17 |
| `WiFi.h`, `WiFiClientSecure.h` | ESP32 board package 2.0.17 |
| `LittleFS.h`, `Preferences.h`, `esp_system.h` | ESP32 board package 2.0.17 |
| `Wire.h`, `EEPROM.h`, `Arduino.h`, FreeRTOS headers | ESP32 board package 2.0.17 |
| `LiquidCrystal_I2C.h` | External LCD library 1.1.4 |
| `WiFiSecrets.h` | Local Wi-Fi settings; copy `WiFiSecrets.example.h` |
| `ServerConfig.h` | Generated by `../../webapp/setup.py --board esp32` |
| Other quoted project headers | Accompanying files in this folder |

If `HTTPClient.h` is missing, install/select the ESP32 board package above.
Do not install ArduinoHttpClient or copy a lone HTTPClient.h into the sketch;
they do not supply the complete ESP32 networking implementation. Restart the
IDE if it does not list a newly installed board package. If ESP32 is selected
and the header is still missing, reinstall the board package through Boards
Manager to repair an incomplete installation.

`platformio.ini` applies to PlatformIO builds only; Arduino IDE does not install
its dependencies or select its board automatically.

After compilation, follow the [complete setup guide](../../README.md) for
one-time LittleFS initialization, HTTPS credentials, upload, and phone pairing.
